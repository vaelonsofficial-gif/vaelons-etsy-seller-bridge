# İş Bitti

Müşteri, randevu, iş geçmişi, bakım ve malzeme takibi için Türkçe uygulama. Uygulama `index.html` dosyasındadır. Kayıtlar tarayıcıda saklanır. Adres veya cihaz değiştirirken kayıtlar JSON yedeğiyle taşınabilir.

## Sonraki sürümler

İş Bitti bağımsız bir web sitesine ve mobil uygulamaya taşınacak. Taşıma sırasında müşteri ve iş kimlikleri, kayıt ilişkileri ve sürüm 1 JSON yedekleri korunmalı. Cihazlar arası eşitleme mevcut sürümde yoktur.
